# Snack privacy and deletion

All Snacks are public. Anyone with the link to a Snack can open it and see its code, so do not put secrets or private code in a Snack. Snack pages tell search engines not to index them.

## Saved Snacks

A Snack that you save to your account has a URL such as `snack.expo.dev/@account/name`. To delete one, open **Snacks** in your account dashboard on [expo.dev](https://expo.dev) and select **Delete** from the Snack's menu. This removes the Snack from your list, but its link continues to work.

## Anonymous Snacks

A Snack that you create without signing in has a random URL. It stops loading 30 days after you create it.

## Removal requests

Expo does not remove Snacks on request. If a Snack contains a secret, such as an API key, revoke it.
